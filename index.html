☁️ Sinkronisasi Firebase Firestore

⚡
Database Akun Terhubung
Semua akun tersimpan di database server & dapat disinkronkan ke Firebase Firestore.
📖 Tutorial Wajib Pengaturan Firebase Klik Buka/Tutup

Langkah Setting di Firebase Console (Hanya 1x):

  1. Buka console.firebase.google.com > Pilih project apar-fss.
  2. Di menu kiri: Build > Firestore Database > Klik Create database (Pilih Region: asia-southeast2 / Jakarta).
  3. Buka tab Rules (Aturan) di bagian atas Firestore Database.
  4. Ubah aturannya menjadi seperti di bawah ini, lalu klik Publish (Publikasikan):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
⚠️ Jika Firestore Database belum dibuat atau Rules ditolak, aplikasi akan otomatis beralih ke Database Server & Cache Lokal sehingga sistem tetap berjalan lancar tanpa macet.
